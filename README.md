# V&V Climatização - site institucional

Site one-page da **V&V Climatização**: instalação, limpeza, manutenção e conserto de ar condicionado em Colônia Vitória, Entre Rios e Guarapuava (PR). Em atividade desde o início de 2022.

## Estrutura

```
index.html   # página única (hero, sobre, serviços, como funciona, contato com mapa, FAQ)
styles.css   # estilos (azul do logo, azul-gelo e laranja do sol, modo claro/escuro automático)
script.js    # menu mobile, header ao rolar, animações de entrada, FAQ
assets/      # logo, marca, favicon e fotos
```

Sem build: HTML, CSS e JS puros. Publique a pasta em GitHub Pages, Netlify, Vercel ou hospedagem comum.

## Logo

- `assets/_originais/` guarda o logo original enviado pelo cliente (fora do git).
- `assets/logo-vv.png`: logo completo reduzido para 900px (rodapé e contato).
- `assets/marca-vv.png` e `favicon.png`: só o "V" sobre um círculo azul-marinho, para o cabeçalho e a aba do navegador.
